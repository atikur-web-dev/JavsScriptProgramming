# Library Management System

You have to build a **Library Management System**.

There will be a base class called `LibraryItem`. Its constructor will take a `title` and an `author`. These two pieces of data must not be directly modifiable from outside the class — they should only be readable.

Each item must have a **unique ID**, which will be automatically generated by the system.

The `getSummary()` method should return:

```text
[id] [title] by [author]
```

## `LibraryItem`

The `LibraryItem` class must have the following methods:

### `borrow()`

At the base level, this method should only throw an error with the message:

```text
borrow() must be implemented by subclass
```

### `getType()`

At the base level, this method should return:

```text
Generic
```

## Custom Error

The system must have a custom error class called `LibraryError` that extends the built-in `Error` class.

Its `name` property must be:

```text
LibraryError
```

All validation errors must be thrown using `LibraryError`.

## `Book`

Create a `Book` class that extends `LibraryItem`.

Its constructor will take:

```text
title, author, isbn
```

The `isbn` must be private.

### `borrow()`

Override `borrow()` to return:

```text
Book: [title] borrowed
```

### `getType()`

Override `getType()` to return:

```text
Book
```

## `Magazine`

Create a `Magazine` class that extends `LibraryItem`.

Its constructor will take:

```text
title, author, issueNumber
```

The `issueNumber` must be private.

### `borrow()`

The `borrow()` method should return:

```text
Magazine: [title] issue [issueNumber] borrowed
```

### `getType()`

Override `getType()` to return:

```text
Magazine
```

## `DVD`

Create a `DVD` class that extends `LibraryItem`.

Its constructor will take:

```text
title, author, duration
```

The `duration` must be private and stored in **minutes**.

### `borrow()`

The `borrow()` method should return:

```text
DVD: [title] ([duration] mins) borrowed
```

### `getType()`

Override `getType()` to return:

```text
DVD
```

## Static Features of `LibraryItem`

### Static Counter

`LibraryItem` must have a private static counter called `#totalItems`.

This counter must increase by `1` every time a new library item is created.

### `getTotalItems()`

Create a static method called `getTotalItems()` that returns the total number of items created.

### Static Factory Method

Create a static factory method:

```js
LibraryItem.create(type, title, author, extra)
```

This method must return the appropriate subclass based on the `type`.

Supported types:

* `"book"` → `Book`
* `"magazine"` → `Magazine`
* `"dvd"` → `DVD`

If an invalid type is provided, a `LibraryError` must be thrown.

## `Library`

Create a `Library` class that maintains a collection of library items.

### Constructor

The constructor must not take any parameters.

It must contain a private `#items` array, which should initially be empty.

### `addItem(item)`

This method should:

* Check whether the argument is an instance of `LibraryItem`.
* If it is not a `LibraryItem`, throw a `LibraryError`.
* Add the item to the `#items` array.
* Return `this` for method chaining.

### `findById(id)`

Find and return an item using its ID.

If no item with the given ID is found, throw a `LibraryError`.

### `borrowItem(id)`

Find the item using its ID, call that item's `borrow()` method, and return the result.

### `getAllTypes()`

Return an array containing the `getType()` result of every item in the library.

### `getTotalItems()`

There should be **no `getTotalItems()` method in the `Library` class**.

The total number of items should be obtained through the static method of `LibraryItem`:

```js
LibraryItem.getTotalItems()
```
