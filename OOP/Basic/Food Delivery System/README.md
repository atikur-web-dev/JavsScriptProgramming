# Food Delivery System

You have to build a **Food Delivery System** where there will be a base class called `OrderItem`.

The constructor will take a `name` and a `price`. These two pieces of data must not be directly modifiable from outside the class — they should only be readable.

Each order item must have a **unique ID**, which will be automatically generated by the system.

The `getSummary()` method should return:

```text
[id] [name] - $[price]
```

## `OrderItem`

The `OrderItem` class must have the following methods:

### `getFinalPrice()`

At the base level, this method should only throw an error with the message:

```text
getFinalPrice() must be implemented by subclass
```

This is because the base class does not know the specific pricing rules.

### `getCategory()`

At the base level, this method should return:

```text
Generic
```

## Custom Error

The system must have a custom error class called `OrderError` that extends the built-in `Error` class.

Its `name` property must be:

```text
OrderError
```

All validation errors must be thrown using `OrderError`.

## `FoodItem`

Create a `FoodItem` class that extends `OrderItem`.

Its constructor will take:

```text
name, price, isVeg
```

The `isVeg` property must be private.

### `getFinalPrice()`

Calculate the final price based on whether the food is vegetarian:

* If `isVeg` is `true`, add **5% tax**.
* If `isVeg` is `false`, add **10% tax**.

### `getCategory()`

Return:

```text
Food
```

## `DrinkItem`

Create a `DrinkItem` class that extends `OrderItem`.

Its constructor will take:

```text
name, price, size
```

The `size` property must be private.

Possible sizes are:

* `"small"`
* `"medium"`
* `"large"`

### `getFinalPrice()`

Calculate the final price based on the drink size:

* `small` → **0% extra**
* `medium` → **10% extra**
* `large` → **20% extra**

### `getCategory()`

Return:

```text
Drink
```

## `ComboItem`

Create a `ComboItem` class that extends `OrderItem`.

Its constructor will take:

```text
name, price, items
```

The `items` property must be a private array.

### `getFinalPrice()`

Apply a **15% discount** to the combo price.

### `getCategory()`

Return:

```text
Combo
```

## Static Features of `OrderItem`

### Static Counter

`OrderItem` must have a private static counter called `#totalItems`.

This counter must increase by `1` every time a new item is created.

### `getTotalItems()`

Create a static method called `getTotalItems()` that returns the total number of items created.

### Static Factory Method

Create a static factory method:

```js
OrderItem.create(type, name, price, extra)
```

This method must return the appropriate subclass based on the `type`.

Supported types:

* `"food"` → `FoodItem`
* `"drink"` → `DrinkItem`
* `"combo"` → `ComboItem`

If an invalid type is provided, an `OrderError` must be thrown.

# `Order`

Create an `Order` class that represents a **single order**.

## Constructor

The constructor will take a `customerName`.

The `customerName` must be private and can only be read through:

```js
getCustomerName()
```

The `Order` class must also contain:

* A private `#items` array, initially empty.
* A private `#orderId` generated automatically by the system.
* A private static counter `#totalOrders`, which increases by `1` whenever a new order is created.

## `addItem(item)`

This method should:

* Check whether the argument is an instance of `OrderItem`.
* If it is not an `OrderItem`, throw an `OrderError`.
* Add the item to the `#items` array.
* Return `this` for method chaining.

## `getTotal()`

Calculate and return the total price of the order by adding the `getFinalPrice()` result of every item.

If an order-level discount has been applied, the discount must be applied to the total **after** all item prices have been calculated.

## `getAllCategories()`

Return an array containing the `getCategory()` result of every item in the order.

## `getOrderSummary()`

Return a string in the following format:

```text
Order [orderId] for [customerName]: $[total]
```

The `[total]` must be the result of `getTotal()`.

## `getTotalOrders()`

Create a static method called `getTotalOrders()` that returns the total number of orders created.

# Order Discount

**New Concept — Special Requirement**

The `Order` class must have a private field called `#discount`, which initially starts at `0`.

## `applyDiscount(percent)`

Create an `applyDiscount(percent)` method that applies an additional discount to the entire order.

The method must:

* Validate that `percent` is between `0` and `100`.
* If the value is outside this range, throw an `OrderError`.
* Set `#discount` to the provided percentage.
* Return `this` for method chaining.

The `getTotal()` method must be modified so that the order-level discount is applied to the final total.

### Important

The discount must be applied **after** adding the `getFinalPrice()` of all items.

The order-level discount must **not** be applied individually to each item's price.

For example:

```text
Item 1 Final Price = $100
Item 2 Final Price = $50

Subtotal = $150

Order Discount = 10%

Final Total = $135
```
